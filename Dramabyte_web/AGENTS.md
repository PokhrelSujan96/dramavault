# Project instructions

The user previews the website themselves. Do not open, preview, screenshot, or inspect the website in a browser unless the user explicitly changes this instruction. Work on code and use code checks, unit tests, and builds for verification.

Preserve the existing onion architecture. Keep domain and application logic independent of infrastructure; compose dependencies in pages and server actions.

Keep each widget and page in a separate file. Keep new or edited files under 200 lines. Do not add comments to code files.

Use real backend data for the homepage. Keep credentials and authenticated backend requests on the server. Do not substitute demo catalog data when the backend is unavailable.
