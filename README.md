# dramavault

Dramabyte source workspace.

- `Dramabyte_web`: viewer website built with Next.js.
- `dramabyte_app`: Flutter mobile application.
- `dramabyte_backend`: backend API, production services, and database migrations.
- `dramabyte_management`: management dashboard.

See each project's README for setup instructions. Configure credentials locally using the available `.env.example` files. Dependencies, build outputs, generated media, model binaries, and local credentials are excluded from version control.
